# 📘 강의용 교안 만들기 (supported by 영업지원팀)

영어 지문을 넣으면 **구조분석 및 끊어 읽기 직독직해**를 수행하고, A4 규격(20% 필기 여백 포함) **강의용 교안 PDF**를 자동으로 생성해 주는 파이썬 기반 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **영어 지문 구문 및 구조분석 (Syntactic Analysis)**
   - 문장별 주어 `[S]` / 동사 `[V]` 자동 감지 및 표시
   - 수식어구 `<전치사구>` 및 수식절 `(관계사절/부사절)` 자동 추출
   - 의미 단위별 **끊어 읽기 슬래시 (`/`)** 구문 분할

2. **직독직해 및 핵심 어휘 정리**
   - 끊어 읽기 단위별 직독직해 가이드 생성
   - 지문 내 주요 수능/모의고사 필수 어휘 목록 자동 추출 및 뜻 제공

3. **A4 인쇄 범위 20% 여백 레이아웃 (강의용 교안 PDF)**
   - 본문 80% + 오른쪽/하단 **필기 및 노트 정리 공간 20% 여백** 적용
   - 브라우저 고화질 A4 즉시 인쇄 (`Ctrl + P`) 및 서버 PDF 다운로드 동시 지원

4. **Vercel & 로컬 호스트 호환**
   - 로컬 호스트 (`http://localhost:5000`) 원클릭 구동
   - GitHub 연동으로 **Vercel** 서버리스 무료 배포 지원

---

## 🚀 로컬 실행 방법 (Local Host)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 로컬 웹 서버 실행
- **방법 1 (원클릭 실행)**: `run.bat` 파일 더블클릭
- **방법 2 (파이썬 스크립트 실행)**:
  ```bash
  python run_local.py
  ```
실행 시 자동으로 브라우저에서 `http://localhost:5000` 접속 주소가 열립니다.

---

## 🌐 Vercel 배포 방법 (Deploy to Vercel via GitHub)

1. 이 프로젝트 폴더 전체를 본인의 **GitHub 리포지토리**에 푸시(Push)합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **New Project**를 클릭합니다.
3. 깃허브 리포지토리를 선택(Import)하고 **Deploy** 버튼을 누릅니다.
4. `vercel.json` 설정에 따라 자동으로 파이썬 서버리스 앱으로 배포가 완료됩니다!
